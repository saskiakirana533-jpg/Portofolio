Tentang Saya

Educational Technology

Menghubungkan Ilmu Komputer dengan Metodologi Pembelajaran

Saya adalah mahasiswa Pendidikan Ilmu Komputer Universitas Pendidikan Indonesia (UPI) asal Cirebon. Ketertarikan saya berpusat pada bagaimana teknologi web dapat dimanfaatkan untuk menyederhanakan konsep-konsep matematika dan ilmu komputer yang kompleks menjadi media interaktif yang mudah dipahami.

Selain aktif mengasah logika pemrograman murni melalui algoritma dan struktur data, saya terus mendalami ekosistem pengembangan web modern (HTML, CSS, JavaScript, React, dan TypeScript). Saya berprinsip bahwa kode yang baik tidak hanya efisien, tetapi juga dapat diakses dan memberikan dampak nyata bagi pengguna.
